- **Client Secret**: `nST8TYE78oANwe6dvhMiCQQZfthIoWlG`

### 3. Proxy Configuration
- Toggle **"Use Proxy"** to ON to route requests through the local server (`http://localhost:8000/proxy`). This resolves CORS issues during testing.

### 4. Generate Token
Click **"Get Access Token"** to authenticate. The token will be automatically populated in the "Access Token" field.

### 5. Create Transaction
- Click **"Create Transaction"** to receive a payment link.
- Default test data for Ecuador (CI) is provided.

### 6. Complete Payment
Open the payment link in a new tab to view the SmartFastPay HPP.

### 7. Verify Status & Webhooks
- Click **"Check Status"** to retrieve the latest transaction status.
- Switch to the **"Webhooks Received"** tab to see incoming notifications from the provider (polled every 5 seconds).
