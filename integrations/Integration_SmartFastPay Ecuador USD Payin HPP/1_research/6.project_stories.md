# Step 6: Project Stories

**File**: `1_research/6.project_stories.md`

## 1. Authorization
*   **Story**: "As a System, I need to authenticate with SmartFastPay to create transactions."
*   **Tech**:
    *   **Endpoint**: `POST /oauth2/token`
    *   **Method**: Basic Auth (`Base64(CLIENT_ID:CLIENT_SECRET)`).
    *   **Output**: Capture `access_token` and cache for `expires_in` (3600s).
    *   **Retry**: If 401 on Transaction, refresh token retry once.

## 2. Create Transaction Request
*   **Story**: "As a System, I need to create a deposit transaction."
*   **Endpoint**: `POST /v2/transaction/checkout`
*   **Header**: `Authorization: Bearer <access_token>`
*   **Payload Mapping**:
    *   `country`: "ECU"
    *   `payment_method`: "bank_transfer"
    *   `transaction.amount`: Request Amount (Decimal, e.g. 10.00).
    *   `transaction.currency`: "USD"
    *   `transaction.description`: Order ID or Brand Name.
    *   `customer.name`: User Full Name.
    *   `customer.email`: User Email.
    *   `customer.document.type`: "CI" or "RUC" (Map from user data or default to "CI" if generic).
    *   `customer.document.number`: User Tax ID.
    *   `url_callback`: Webhook URL.
    *   `url_redirect`: Return URL.

## 3. Create Transaction Response
*   **Story**: "As a System, I need to handle the creation response."
*   **Success (200 OK)**:
    *   Parse `data.url` (or root `url`).
    *   Action: Redirect user to this URL.
*   **Error (4xx/5xx)**:
    *   Parse `moreInformation[0].message` or `detail`.
    *   Action: Return specific error to user.

## 4. Callback (Webhook)
*   **Story**: "As a System, I need to process payment notifications."
*   **Validation**:
    *   Header: `SmartFastPay-Signature`: `t=...,v1=...`
    *   Algo: `HMAC-SHA256(CLIENT_SECRET, t + "." + JSON_BODY)` === `v1`.
    *   Check `t` for replay attack (within 5 mins).
*   **Processing**:
    *   Extract `transaction.status`.
    *   ID Match: `callbackId` (or `orderId` in payload).

## 5. Final Statuses
*   **Provider -> Internal**:
    *   `COMPLETED` / `PAID` -> **Success**
    *   `REJECTED` / `FAILED` -> **Fail**
    *   `PENDING` / `CREATED` -> **Pending**
    *   `EXPIRED` -> **Fail**

## 6. Error Mapping
*   `INVALID_AUTH_CODE` -> Configuration Error.
*   `INVALID_PARAMETER` -> Validation Error (User Input).
