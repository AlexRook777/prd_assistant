## Authentication

### Method
OAuth 2.0 with Client Credentials.

### Token Generation
- **Endpoint**: `https://api.smartfastpay.com/oauth/token` (Sandbox: `https://sandbox.smartfastpay.com/oauth/token`) *[To Verify exact path]*
- **Required Headers**: 
  - `Content-Type: application/json` or `application/x-www-form-urlencoded`
  - `Authorization: Basic <base64(client_id:client_secret)>`
- **Request Body**:
  ```json
  {
    "grant_type": "client_credentials"
  }
  ```
- **Response**:
  ```json
  {
    "access_token": "eyJhbGc...",
    "expires_in": 3600,
    "token_type": "Bearer"
  }
  ```

## API Endpoints

### Create Transaction (Payin - HPP)
- **Endpoint**: `POST /v2/payin`
- **Authentication**: `Bearer <Access-Token>`
- **Required Parameters**:
  - `customer.id` (string, required)
  - `customer.name` (string, required)
  - `customer.document.number` (string, required) - National ID
  - `customer.document.type` (string, required) - e.g., "CC"
  - `customer.phone` (string, E.164, required)
  - `transaction.id` (string, required)
  - `transaction.currency` (string, "USD" for Ecuador)
  - `transaction.amount` (decimal 10,2)
  - `country` (string, "ECU")
  - `payment_method` (string, "bank_transfer")
  - `notification_url` (string, required)
- **Response**:
  ```json
  {
    "requestId": "...",
    "data": {
      "url": "https://sandbox.smartfastpay.com/checkout/v1/...",
      "transaction_id": "..."
    }
  }
  ```
  *The `data.url` is the HPP link to redirect the user to.*

### Create Payout (Withdrawal)
- **Endpoint**: `POST /v2/payout`
- **Authentication**: `Bearer <Access-Token>`
- **Required Parameters**:
  - `customer.id` (string, required)
  - `customer.name` (string, required)
  - `customer.phone` (string, E.164, required)
  - `customer.document.number` (string, required)
  - `customer.document.type` (string, required)
  - `country` (string, "ECU")
  - `payment_method` (string, "bank_transfer")
  - `bank_transfer.bank_code` (string, required)
  - `bank_transfer.bank_account_number` (string, required)
  - `bank_transfer.bank_account_type` (string, "CHECKING" or "SAVINGS")
  - `transaction.id` (string, required)
  - `transaction.currency` (string, "USD")
  - `transaction.amount` (decimal 10,2)

### Check Status

- **Authentication**: Usage of `CLIENT_SECRET` to verify signature is expected.
