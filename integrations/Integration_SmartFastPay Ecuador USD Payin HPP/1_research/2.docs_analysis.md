## Authentication

### Method
OAuth 2.0 Client Credentials

### Token Generation
- **Endpoint**: `POST https://sandbox.smartfastpay.com/oauth2/token`
- **Required Headers**: 
  - `Authorization: Basic <base64(client_id:client_secret)>`
  - `Content-Type: application/json`
- **Request Body**:
  ```json
  {
    "grant_type": "client_credentials"
  }
  ```
- **Response**:
  ```json
  {
    "requestId": "...",
    "data": {
      "access_token": "eyJhbGc...",
      "expires_in": 3600
    }
  }
  ```
- **Verification**: Verified via `curl`. Token obtained successfully.

## API Endpoints

### Create Transaction (Checkout/HPP)
- **Endpoint**: `POST https://sandbox.smartfastpay.com/v2/transaction/checkout`
- **Authentication**: `Bearer <access_token>`
- **Required Parameters**:
  - `customer.id` (string): Unique identifier in system.
  - `customer.name` (string): Full name.
  - `customer.document.number` (string)
  - `customer.document.type` (string): `CC`, `PA`, `RUC` for ECU.
  - `transaction.id` (string): Unique transaction ID.
  - `transaction.currency` (string): `USD`.
  - `transaction.amount` (decimal): Dot as decimal separator.
  - `country` (string): `ECU`.
  - `payment_method` (array): `["bank_transfer"]`.
  - `notification_url` (string): Webhook destination.
- **Optional Parameters**:
  - `customer.email` (string)
  - `customer.phone` (string)
  - `redirect_url` (string)
- **Response**:
  ```json
  {
    "requestId": "...",
    "data": {
      "url": "https://sandbox-checkout.smartfastpay.com/...",
      "transaction_id": "...",
      "expires_in": 1722108649
    }
  }
  ```

### Check Status
- **Endpoint**: `GET https://sandbox.smartfastpay.com/payment/{id}`
- **Authentication**: `Bearer <access_token>`
- **Response Statuses**: `pending`, `success`, `failed`, `onhold`, `returned`, `refunded`.

### Webhook Callback
- **Expected Format**: POST to our callback URL
- **Authentication**: `SmartFastPay-Signature` header.
  - **Algorithm**: Likely HMAC-SHA256 (common for this provider type).
  - **Secret Location**: Dashboard or via API.
- **Payload Structure**: Typically includes `transaction_id` and `status`.

### Error Handling
- **Error JSON Structure**:
  ```json
  {
    "requestId": "...",
    "moreInformation": [
      {
        "code": "INVALID_REQUEST",
        "detail": "Description of error"
      }
    ]
  }
  ```
- **Common Codes**:
  - `INVALID_AUTH_CODE`: Authentication failure.
  - `INVALID_REQUEST`: Missing or invalid parameters.
