# Documentation Analysis

**Provider**: SmartFastPay
**Documentation URL**: https://docs.smartfastpay.com/methods-and-markets/payin/latam/equador/bank-transfer
**Date**: 2026-01-28

## Clarified Points (User Feedback)
- **Flow Type**: Pure HPP (Hosted Payment Page) flow is confirmed.
- **Customer Fields**: Optional, can be filled on the checkout page if not provided.
- **Scope**: Integration is for Ecuador (ECU) with currency USD.
- **Sandbox Environment**: Credentials provided for testing.

## Authentication
### Method
OAuth 2.0 with Bearer Token.

### Token Generation
- **Endpoint**: `POST https://sandbox.smartfastpay.com/oauth2/token`
- **Required Headers**: `Authorization: Basic [BASE64(CLIENT_ID:CLIENT_SECRET)]`, `Content-Type: application/x-www-form-urlencoded`
- **Body**: `grant_type=client_credentials`

### Verification (MANDATORY)
Successfully verified. Obtained token using:

## API Endpoints
### Create Transaction
- **Endpoint**: `POST https://sandbox.smartfastpay.com/v2/payin`
- **Authentication**: Bearer Token
- **Required Parameters**:
  - `customer.id` (string)
  - `customer.name` (string)
  - `customer.document.number` (string)
  - `customer.document.type` (string - e.g., "CC" for ECU)
  - `customer.phone` (string E.164)
  - `transaction.id` (string)
  - `transaction.currency` (string ISO - "USD")
  - `transaction.amount` (decimal 10,2)
  - `country` (string ISO - "ECU")
  - `payment_method` (string - "bank_transfer")
  - `notification_url` (string)
- **Optional Parameters**:
  - None explicitly listed as optional in this context, but commonly `customer.email` if not mandatory.

### Check Status
- **Endpoint**: `GET https://sandbox.smartfastpay.com/transaction/{id}` (Note: NO `/v2/` prefix)
- **Statuses**: `pending`, `paid`, `denied`, `expired`

### Webhook Callback
- **Method**: POST
- **Authentication**: `Webhook-Signature` Header (HMACSHA256)
- **Structure**: JSON body with transaction details.

### Negative Testing (Validation)
| Test Case | Variation | Expected | Actual Code | JSON Error |
|-----------|-----------|----------|-------------|------------|
| Missing ID | Omit `transaction.id` | 400 | 400 | `{"code":"INVALID_REQUEST","detail":"The transaction.id field is required."}` |
| Bad Type | String `amount`: "abc" | 400 | 400 | `{"code":"INVALID_REQUEST","detail":"The transaction.amount must be a number."}` |
| Invalid Doc Type | Type `CI` (Ecuador) | 400 | 400 | `{"code":"INVALID_REQUEST","detail":"The value in field customer.document.number is invalid by type CI"}` |
| Below Minimum | Amount 0.1 USD | 400 | 200 | (Accepted in Sandbox, though Epic says 6 USD min) |

## Gap Analysis (Discrepancies)
| # | Issue | Documentation | Actual Behavior | Severity |
