# Documentation Analysis: SmartFastPay Ecuador USD Payin HPP

## 1. Documentation Sources
*   **Ecuador Bank Transfer**: [SmartFastPay Docs - Ecuador](https://docs.smartfastpay.com/methods-and-markets/payin/latam/equador/bank-transfer)
*   **Checkout/HPP**: [Checkout Experience](https://docs.smartfastpay.com/thesmartway/checkout-experience/overview)
*   **Webhooks**: [Notification & Webhooks](https://docs.smartfastpay.com/thesmartway/notification-and-webhooks)

## 2. Authentication
*   **Type**: OAuth 2.0 (Bearer Token).
*   **Token Endpoint**: `POST /oauth2/token`
    *   **Header**: `Authorization: Basic <Base64(CLIENT_ID:CLIENT_SECRET)>`
    *   **Body**: `{}` (Empty JSON)
    *   **Response**: `{ "access_token": "...", "expires_in": 3600 }`
*   **API Usage**: `Authorization: Bearer <ACCESS_TOKEN>` for all other endpoints (e.g., Checkout).

## 3. Payment Methods & Restrictions
*   **Country**: `ECU`
*   **Currency**: `USD`
*   **Payment Method**: `bank_transfer`
*   **Limits**:
    *   Min: $6.00
    *   Max: $1000.00

## 4. Transaction Creation (HPP)
*   **Endpoint**: `POST /v2/transaction/checkout`
*   **Sandbox**: `https://sandbox.smartfastpay.com/v2/transaction/checkout`
*   **Production**: `https://api.smartfastpay.com/v2/transaction/checkout`
*   **Payload Example**:
    ```json
    {
      "app_id": "{{CLIENT_ID}}",  // Sometimes required in body too?
      "country": "ECU",
      "payment_method": "bank_transfer",
      "url_callback": "https://callback.url",
      "url_redirect": "https://redirect.url",
      "transaction": {
        "amount": 10.00,
        "currency": "USD",
        "description": "Order #12345"
      },
      "customer": {
        "name": "John Doe",
        "email": "customer@example.com",
        "document": {
          "type": "CI", // Cédula de Identidad for Ecuador
          "number": "1234567890"
        }
      }
    }
    ```

## 5. Webhook (Callback) Structure
*   **Method**: `POST`
*   **Signature Header**: `SmartFastPay-Signature`
    *   Format: `t=123456789,v1=abcdef...`
*   **Validation**:
    1.  Extract `t` (timestamp) and `v1` (signature).
    2.  Construct string: `{t}.{json_body}`
    3.  Calculate HMAC-SHA256 using `CLIENT_SECRET`.
    4.  Compare with `v1`.
*   **Response**: Return `200 OK` to acknowledge.
