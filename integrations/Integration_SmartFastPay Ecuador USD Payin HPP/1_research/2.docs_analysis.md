# Documentation Analysis

**Provider**: SmartFastPay  
**Documentation URL**: [https://docs.smartfastpay.com/methods-and-markets/payin/latam/equador/bank-transfer](https://docs.smartfastpay.com/methods-and-markets/payin/latam/equador/bank-transfer)  
**Date**: 2026-01-27

## Authentication

### Method
OAuth 2.0 (Basic Auth for Token, Bearer for API)

### Token Generation
- **Endpoint**: `POST https://sandbox.smartfastpay.com/oauth2/token`
- **Required Headers**: 
  - `Authorization: Basic <base64(client_id:client_secret)>`
  - `Content-Type: application/json`
  - `Accept: application/json`
- **Request Body**: (Authentication is handled via the Basic header)
- **Response**:
  ```json
  {
    "access_token": "...",
    "token_type": "Bearer",
    "expires_in": 3600
  }
  ```

## API Endpoints

### Create Transaction (Hosted Payment Page - HPP)
- **Endpoint**: `POST /v2/transaction/checkout`
- **Authentication**: Bearer Token
- **Required Parameters**:
  - `customer.id` (string)
  - `customer.name` (string, optional on checkout)
  - `customer.document.number` (string)
  - `customer.document.type` (string, e.g., "CC")
  - `transaction.id` (string)
  - `transaction.currency` (string, e.g., "USD")
  - `transaction.amount` (decimal 10,2)
  - `country` (string, ISO 3166-1 alpha-3, e.g., "ECU")
  - `payment_method` (array of strings)
  - `notification_url` (string)
  - `redirect_url` (string, optional)

### Create Transaction (Direct Payin)
- **Endpoint**: `POST /v2/payin`
- **Authentication**: Bearer Token
- **Required Parameters**: Same as checkout, but `payment_method` is a single string.

### Check Status
- **Endpoint**: `GET /transaction/{id}` or `GET /payment/{id}`
- **Authentication**: Bearer Token
- **Response Statuses**: `pending`, `paid`, `cancelled`, `refunded`, etc.

### Webhook Callback
- **Expected Format**: POST to our callback URL
- **Authentication**: `SmartFastPay-Signature` header (verified using secret from `/webhook/secret`)
- **Payload Structure**:
  ```json
  {
    "callback": true,
    "data": [
      {
        "id": "...",
        "customer_id": "...",
        "transaction_id": "...",
        "amount": "...",
        "currency": "...",
        "status": "paid",
        "payment_method": "...",
        "payment_status": "paid"
      }
    ]
  }
  ```

## Required Customer Fields (Ecuador)

| Field | Format | Required | Example |
|-------|--------|----------|---------|
| `id` | String | Yes | `cust_123` |
| `name` | String | Yes* | `John Doe` |
| `email` | Email | No | `user@example.com` |
| `phone` | E.164 | Yes | `+593991234567` |
| `document.number` | String | Yes | `1712345678` |
| `document.type` | String | Yes | `CC` |

**Note**: `customer.name` is optional on `/v2/transaction/checkout` but expected in `/v2/payin`.

## Restrictions & Quirks
- **Limits**: Min 6 USD, Max 1,000 USD per transaction for Ecuador.
- **Document Types**: Use `CC` for Ecuador Citizenship Card. Detailed list available via `GET /documents-type?country=ECU`.
- **Sandbox vs Production**: Use `sandbox.smartfastpay.com` for testing.
- **Hosted Checkout**: The XML suggests using the Hosted Payment Page (HPP) flow.
