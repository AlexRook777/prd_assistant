# Epic Analysis

**Integration Name**: SmartFastPay - Ecuador/Peru - USD/PEN - Bank Transfer  
**Date**: 2026-01-27

## Summary
The project involves integrating the SmartFastPay payment provider to support Bank Transfers in Ecuador (USD) and Peru (PEN). The integration will primarily use the provider's Hosted Payment Page (HPP/Checkout) flow, with H2H as a fallback. A key feature is that SmartFastPay can collect missing customer information on their side if it's not provided in the initial API request.

Initially, the focus is on Bank Transfers (Payin and Payout), with other methods to follow.

## Requirements
- **Payment Methods**: Bank Transfer (priority), others later.
- **Countries**: Ecuador, Peru.
- **Currencies**: USD (Ecuador), PEN (Peru).
- **Flow Type**: HPP (Primary), H2H (Fallback).
- **Transaction Types**: Payin (Deposit), Payout (Withdrawal).
- **Limits**:
    - **Ecuador**: Min 6 USD, Max 1,000 USD. Daily user limit: 1,200 USD, Monthly: 36,000 USD.
    - **Peru**: Min 25 PEN, Max 3,700 PEN. Daily user limit: 11,100 PEN, Monthly: 18,500 PEN.
- **Languages**: Spanish, English.
- **Fields to be passed (if available)**: Amount, name, tax_id_type, tax_id, email.
- **Performance**: Expected conversion rate 70%+.

## Technical Constraints
- **Integration Flow**: SmartFastPay Checkout experience (HPP).
- **Fallback**: H2H capability required as a fallback.
- **Customer Fields**: If not provided in the request, the provider's checkout page will ask the user for them.
- **Status Tracking**: Webhooks are the primary method for tracking transaction status.
- **Documentation**: The XML notes that current documentation might not be 100% actual; specifically, customer fields might not be mandatory in the `create` request.
- **Timeline**: Standard HPP integration should be quick (as per PO comments).
