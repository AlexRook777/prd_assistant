# Test Page: SmartFastPay Ecuador USD Payin HPP

This page allows you to physically verify the SmartFastPay API behavior and test webhooks for the Ecuador USD Payin HPP integration.

## Files
- [3.test_page.html](file:///home/worker/repos/prd_assistant/integrations/Integration_SmartFastPay%20Ecuador%20USD%20Payin%20HPP/1_result/3.test_page.html) - Functional test console.

## Prerequisites
1.  **Local Proxy Server**: You MUST have the local development server running to handle CORS and webhooks.
    ```bash
    python3 app/serve.py
    ```
2.  **API Credentials**: Ensure you have a valid `Client ID` and `Client Secret` (pre-filled in the HTML from `integration_config`).

## Usage Instructions
1.  **Open the Test Page**: Open `3.test_page.html` in your browser.
2.  **Enable Proxy**: Toggle the **"Use Proxy"** switch in the "API Credentials" card.
3.  **Get Token**: Click "Get Token" to obtain an OAuth 2.0 access token.
4.  **Create Transaction**: 
    - Fill in the transaction details.
    - Click "Create Transaction".
    - A payment link (Checkout URL) will be generated and displayed.
5.  **Complete Payment**: Click the generated link to open the SmartFastPay HPP in a new tab and complete the payment.
6.  **Check Status**: Return to the test page and click "Check Status" to verify the transaction state.
7.  **View Webhooks**: Switch to the "Webhooks" tab to see real-time notifications received by the local server.

## Tips
- **Sandbox Validation**: For Ecuador sandbox, use "PA" (Passport) as the document type if "CC" (Cedula) validation is too strict.
- **Webhook Polling**: The page automatically polls for new webhooks every 5 seconds.
