## Usage Instructions

1. **Start Local Server**:
   Ensure the local server is running to support the Proxy and Local Webhooks:
   ```bash
   python3 serve.py
   ```

2. **Open Test Page**:
   Open [3.test_page.html](file:///home/worker/repos/prd_assistant/integrations/Integration_SmartFastPay%20Ecuador%20USD%20Payin%20HPP/1_result/3.test_page.html) in your browser.

3. **Get Access Token**:
   - Verify `Client ID` and `Client Secret` are filled.
   - Click **Get Token**. The token will appear in the text area and be logged in the API Logs.

4. **Create Transaction**:
   - The **Order ID** and **Notification URL** are auto-generated.
   - Review the **Customer Info** (pre-filled with valid Ecuador CI example).
   - Click **Create Transaction**.
   - If successful, a **Payment Link** will appear.

5. **Complete Payment**:
   - Click the link to open the SmartFastPay Checkout in a new tab.
   - Follow the provider's instructions to complete the payment.

6. **Verify Results**:
   - Click **Check Status** to see the transaction status in the logs.
   - Monitor the **Webhooks** section (auto-polls every 5 seconds).

## Configuration Details

### Proxy Settings
- **Default**: ON (Recommended to avoid CORS issues).
- **Endpoint**: `http://localhost:8000/proxy`.

### Webhook Modes
- **N8n Webhooks** (Default): Uses the global n8n infrastructure for reliable external callbacks.
- **Local Webhooks**: Uses the local `serve.py` listener (requires public tunnel like ngrok if testing real provider callbacks).
