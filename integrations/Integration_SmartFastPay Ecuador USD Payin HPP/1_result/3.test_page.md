# Test Page: SmartFastPay Ecuador

Functional test page for verifying the SmartFastPay Ecuador (USD) HPP integration.

## Files
- **Functional Page**: [3.test_page.html](file:///home/worker/repos/prd_assistant/integrations/Integration_SmartFastPay%20Ecuador%20USD%20Payin%20HPP/1_result/3.test_page.html)

## Usage Instructions

### 1. Preparation
- Ensure you have a local proxy running at `http://localhost:8000` (optional, but recommended for CORS).
- Open `3.test_page.html` in your browser.

### 2. Authentication
- The credentials (Client ID and Secret) are pre-filled based on the current configuration.
- Click **"Get Token"**. This will perform an OAuth 2.0 flow using Basic Authentication.
- The generated Bearer token will be automatically populated in the "Access Token" field.

### 3. Creating a Transaction
- Review the transaction fields. Mandatory fields are marked with `*`.
- **Note**: The `Transaction ID` is automatically generated but can be modified.
- **Webhook Selection**: Choose between **Local Mode** (using `serve.py`) or **N8n Mode**.
- Click **"Create Transaction"**.
- If successful, a payment link and the provider's UID will appear.

### 4. Verification
- Click the generated **payment link** to open the SmartFastPay checkout page in a new tab.
- Complete the payment flow in the sandbox environment.
- Use the **"Check Status"** button to manually poll the provider's API for the current transaction status.
- Monitor the **"Webhooks"** section for incoming notifications. Polling happens automatically every 5 seconds.
