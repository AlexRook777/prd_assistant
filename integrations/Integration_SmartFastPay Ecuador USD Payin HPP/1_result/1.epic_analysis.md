# Epic Analysis

**Integration Name**: SmartFastPay Ecuador USD Payin HPP

## Summary
The project aims to integrate **SmartFastPay**, a new payment provider, specifically for **Bank Transfer** (Payin) in **Ecuador**. The integration will utilize the provider's **Checkout (HPP)** flow, which generates a redirection URL for the customer to complete the payment.

> [!NOTE]
> While Peru was initially mentioned in the Jira Epic, the current scope is limited to **Ecuador only**.

## Clarified Points (User Feedback)

- **SLA**: Technical response time expectations are currently **unknown**.
- **Scope**: Integration is currently for **Ecuador only**. Peru is excluded for now.

## Requirements
- Support **Bank Transfer** as the primary payment method.
- Target country: **Ecuador (ECU)**.
- Target languages: **Spanish** and **English**.
- **Transaction Limits (ECU)**:
    - Min: 6 USD, Max: 1,000 USD.
    - User limits: 1,200 USD/daily, 36,000 USD/monthly.
- Expected conversion rate: **70%+**.
- Checkout page must display provider's name (HPP).

## Technical Constraints

- Customer fields are **not required** during transaction creation (can be filled on the provider's checkout page).
- Technical support is available via **Telegram** (to be created).
