# Epic Analysis

**Integration Name**: SmartFastPay - Ecuador - USD - Bank Transfer Payin HPP  
**Date**: 2026-02-12

## Summary
- **Payment Method**: Bank Transfer
- **Countries**: Ecuador
- **Currencies**: USD
- **Flow Type**: HPP (Redirect to PayUrl)
- **Transaction Types**: Payin

The integration focuses on implementing SmartFastPay's HPP (Hosted Payment Page) flow for Bank Transfers in Ecuador. The process involves a server-side request to generate a `pay_url`, where the user can complete the payment. The merchant has the option to pre-fill customer data (Amount, name, tax_id_type, tax_id, email) or let the user enter it on the provider's checkout page.

## BetterBro Alignment (Draft)
- **Service Rule**: Acquiring Form / HPP
- **BetterBro Service URL**: [https://docs.betterbro.com/services/ecuador/bank_transfer/payin_hpp](https://docs.betterbro.com/services/ecuador/bank_transfer/payin_hpp)

## Requirements
- Support for Bank Transfer payins in Ecuador (USD).
- Use of SmartFastPay "Checkout Experience" (HPP).
- Capability to handle pre-filled customer data or missing data on the checkout page.
- Compliance with Ecuador-specific transaction and user limits (Min: 6 USD, Max: 1,000 USD).
- Localization support for Spanish and English.

## Technical Constraints
- **Document Accuracy**: Business requirements note that provider documentation may not be fully up to date.
- **Request Structure**: Customer fields should NOT be sent in the initial create request if they are to be handled by the HPP.
- **Environment**: Test and Production credentials are already available.

## Clarified Points (User Feedback)
- **HPP vs H2H**: Strictly HPP flow.
- **Payouts**: Out of scope for this integration.
- **IP Whitelisting**: Not required for callbacks/webhooks.
- **Scope Restriction**: Ecuador only (Peru is excluded).
