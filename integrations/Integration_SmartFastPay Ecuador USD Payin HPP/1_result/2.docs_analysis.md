# Documentation Analysis

**Provider**: SmartFastPay
**Documentation URL**: https://docs.smartfastpay.com/thesmartway/checkout-experience/overview
**Date**: 2026-02-04

## Clarified Points (User Feedback)
- **Integration scope**: Ecuador (USD) only.
- **Flow type**: HPP (Hosted Payment Page).
- **Payout scope**: Not required for this stage.

## Authentication
### Method
OAuth 2.0 with Bearer Token. Credentials (Client ID and Secret) must be sent using Basic Authentication in the token request.

### Token Generation
- **Endpoint**: `POST https://sandbox.smartfastpay.com/oauth2/token`
- **Required Headers**: 
    - `Content-Type: application/x-www-form-urlencoded`
    - `Authorization: Basic [Base64(client_id:client_secret)]`
- **Required Data**: `grant_type=client_credentials`
- **Token Lifetime**: 3600 seconds (1 hour).

### Verification (MANDATORY)
Successfully verified. Obtained token using:
```bash
curl -X POST "https://sandbox.smartfastpay.com/oauth2/token" \
     -H "Authorization: Basic [REDACTED]" \
     -H "Content-Type: application/x-www-form-urlencoded" \
     -d "grant_type=client_credentials"
```

## Transaction Initiation
### Create Transaction Endpoint
- **Endpoint**: `POST https://sandbox.smartfastpay.com/v2/transaction/checkout`
- **HTTP Method**: POST
- **Request Format**: `application/json`
- **Authentication**: Bearer Token in `Authorization` header.

### Data Structure
#### Mandatory Fields
| Field | Type | Format | Description | Example |
|-------|------|--------|-------------|---------|
| `customer.id` | string | UUID/String | Customer unique ID | "cust_12345" |
| `customer.name` | string | String | Customer full name | "Juan Perez" |
| `customer.email` | string | Email | Customer email | "juan.perez@example.com" |
| `customer.tax_id_type` | string | String | Document Type (CI/RUC for ECU) | "CI" |
| `customer.tax_id` | string | String | Document Number | "1712345678" |
| `transaction.id` | string | String | Your unique order ID | "order_789" |
| `transaction.currency` | string | ISO 4217 | Currency code | "USD" |
| `transaction.amount` | number | Decimal(10,2) | Amount | 10.00 |
| `country` | string | ISO 3166-1 alpha-3 | Country code | "ECU" |
| `payment_method` | array[string] | Array | List of methods | ["bank_transfer"] |
| `notification_url` | string | URL | Webhook callback URL | "https://..." |

#### Optional Fields
| Field | Type | Format | Description | Default |
|-------|------|--------|-------------|---------|
| `redirect_url` | string | URL | Redirect after payment | null |
| `branch` | string | String | Branch identifier | null |

### Expected Results
- **Success Status Code**: 200 OK / 201 Created
- **Response Structure**:
```json
{
  "requestId": "...",
  "timestamp": "2026-02-04T...",
  "data": {
    "url": "https://sandbox-checkout.smartfastpay.com/v1/...",
    "transaction_id": "40790dc7-cb37-4c23-845c-941f2fb332ad",
    "expires_in": 1770230508
  }
}
```
- **Transaction ID Format**: UUID-like (e.g., `40790dc7-cb37-4c23-845c-941f2fb332ad`)
- **Transaction ID Location**: `data.transaction_id`

## Payment URL Response
- **URL Location**: `data.url`
- **URL Format**: `https://sandbox-checkout.smartfastpay.com/v1/{uuid}/{encoded_method}/{encoded_extra}`
- **URL Lifetime**: ~15-20 minutes (based on `expires_in` timestamp)
- **Redirect Behavior**: Redirects user to checkout page.

## Status Sets
### Complete Status List (Payments)
| Status | Description | Type | Next Possible States |
|--------|-------------|------|---------------------|
| `pending` | Created, awaiting payment | Intermediate | paid, denied, expired |
| `paid` | Payment successful | Final | - |
| `denied` | Payment failed/rejected | Final | - |
| `expired` | session timed out | Final | - |

### Status Flow
```
pending → paid (success)
pending → denied (failure)
pending → expired (timeout)
```

## API Endpoints
### Check Status
- **Endpoint**: `GET https://sandbox.smartfastpay.com/v2/transaction/{id}`
- **Authentication**: Bearer Token

### Webhook Callback
- **Format**: POST to merchant-provided URL
- **Authentication**: Signature for Webhook Notifications (documented in security set)
- **Payload Structure**: Typically includes `transaction_id`, `status`, `amount`, and `currency`.
