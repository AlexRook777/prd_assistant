# Documentation Analysis

**Provider**: SmartFastPay
**Documentation URL**: https://docs.smartfastpay.com/thesmartway/checkout-experience/overview
**Date**: 2026-02-02

## Clarified Points (User Feedback)
- **Scope**: Ecuador only (USD).
- **Payment Method**: Bank Transfer (primary), all payment methods for Ecuador.
- **Tax ID Type**: User requested `CI`, but API testing reveals `CI` is not supported for Ecuador. Supported types are `CC` (National ID) and `RUC` (Tax ID).

## Authentication
### Method
OAuth 2.0 with Basic Auth for token generation, Bearer Token for API calls.

### Token Generation
- **Endpoint**: `POST https://sandbox.smartfastpay.com/oauth2/token`
- **Required Headers**: 
  - `Content-Type: application/x-www-form-urlencoded`
  - `Authorization: Basic <Base64(clientId:clientSecret)>`
- **Body**: `grant_type=client_credentials`

### Verification (MANDATORY)
Successfully verified. Obtained token using:
```bash
curl -X POST https://sandbox.smartfastpay.com/oauth2/token \
     -H "Content-Type: application/x-www-form-urlencoded" \
     -u "fd8111f7-6ace-4789-b05a-40a6a36cb0be:nST8TYE78oANwe6dvhMiCQQZfthIoWlG" \
     -d "grant_type=client_credentials"
```

## API Endpoints
### Create Transaction (Checkout)
- **Endpoint**: `POST https://sandbox.smartfastpay.com/v2/transaction/checkout`
- **Authentication**: Bearer Token
- **Required Parameters**:
  - `customer.id` (string)
  - `transaction.id` (string)
  - `transaction.currency` (string, e.g., "USD")
  - `transaction.amount` (decimal/numeric)
  - `country` (string, "ECU")
  - `payment_method` (array of strings, e.g., ["bank_transfer"])
  - `notification_url` (string)
- **Optional/Pre-fill Parameters**:
  - `customer.name`
  - `customer.email`
  - `customer.document.number`
  - `customer.document.type` ("CC" or "RUC" for Ecuador)
  - `redirect_url`

### Check Status
- **Endpoint**: `GET https://sandbox.smartfastpay.com/v2/transaction/{id}`
- **Statuses**: `open`, `pending`, `paid`, `canceled`, `refunded`

### Webhook Callback
- **Format**: POST
- **Headers**: `SmartFastPay-Signature: t=TIMESTAMP,v1=SIGNATURE`
- **Security**: HMAC-SHA256
- **Signature String**: `timestamp + "." + json_payload`
- **Secret**: Account secret UID.

| Invalid Doc Type | `type: "CI"`        | 400      | 400         | `{"code":"INVALID_REQUEST","detail":"Document type CI not found"}`            |

## Gap Analysis (Discrepancies)
| #   | Issue            | Documentation / Goal    | Actual Behavior                    | Severity |
| --- | ---------------- | ----------------------- | ---------------------------------- | -------- |
| 1   | Document Type CI | Goal was `CI`           | API rejects `CI`, requires `CC`    | Medium   |
| 2   | Status Endpoint  | Not always clear if v2/ | Verified and works at `/v2/`       | Low      |
| 3   | Customer Details | Optional per some docs  | Required for pre-fill, else on HPP | Low      |
