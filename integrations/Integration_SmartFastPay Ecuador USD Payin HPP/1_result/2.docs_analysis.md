# Documentation & API Verification: SmartFastPay Ecuador USD Payin HPP

Analysis of the SmartFastPay Checkout API for integration in Ecuador.

## Research Findings

### Authentication Method
- **Method**: OAuth 2.0 (Client Credentials grant)
- **Token Endpoint**: `https://sandbox.smartfastpay.com/oauth2/token`
- **Credentials**: `CLIENT_ID` and `CLIENT_SECRET` sent via Basic Authentication.
- **Request Format**: `application/x-www-form-urlencoded` with `grant_type=client_credentials`.
- **Usage**: Token is sent in the `Authorization` header as `Bearer <Access-Token>`.

### Transaction Initiation
- **Endpoint**: `POST https://sandbox.smartfastpay.com/v2/transaction/checkout`
- **Format**: JSON
- **Description**: Creates a transaction and returns a redirection URL (HPP) for the customer to complete the payment.

### Data Structure - Request Fields

| Field | Type | Required? | Description |
|-------|------|-----------|-------------|
| `customer.id` | string | Yes | Unique identifier for the customer in your system. |
| `transaction.id` | string | Yes | Unique identifier for the transaction (Order ID). |
| `transaction.currency` | string | Yes | ISO 4217 currency code (e.g., `USD` for Ecuador). |
| `transaction.amount` | decimal | Yes | Total transaction amount (e.g., `10.00`). |
| `country` | string | Yes | ISO 3166-1 alpha-3 code (e.g., `ECU` for Ecuador). |
| `payment_method` | array[string] | Yes | List of payment methods (e.g., `["bank_transfer"]`). |
| `notification_url` | string | Yes | Webhook URL for transaction updates. |
| `customer.name` | string | No* | Full name of the customer. Required if not provided on HPP. |
| `customer.email` | string | No* | Email address of the customer. |
| `customer.document.number`| string | No* | Identification number (e.g., `1701234567`). |
| `customer.document.type` | string | No* | Document type code (e.g., `CC`, `PA`, `RUC`). |
| `branch` | string | No | Branch or location identifier. |
| `redirect_url` | string | No | URL to redirect user after payment completion/failure. |

\*Note: These fields are optional for the API request but may be required for the customer to fill on the checkout page if not provided.

### Payment URL Response
- **Location**: `data.url`
- **Format**: A secure SmartFastPay checkout URL.
- **Example**: `https://sandbox-checkout.smartfastpay.com/v1/...`
- **Expiration**: Indicated in `data.expires_in` (seconds or timestamp).

### Callbacks (Webhooks)
- **Configuration**: Set per transaction via `notification_url`.
- **Method**: POST
- **Payload**: JSON containing `transaction_id`, `status`, `amount`, and other details.

### Status Sets (Payin)
- `pending`: Payment is awaiting processing or user action.
- `paid`: Payment has been successfully completed.
- `denied`: Payment was rejected.
- `expired`: Payment request time limit exceeded.
