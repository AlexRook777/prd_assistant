# Initial Documentation

This folder contains **immutable** source documents for the integration:

## Required Files
1. **Epic/Jira Requirements**: 
   - Copy the Epic description or Jira ticket here
   - Save as `epic_requirements.md` or paste Jira link

2. **Provider API Documentation**:
   - Download provider's API documentation PDFs
   - Save provider-specific implementation guides
   - Include any authentication guides or sandbox setup docs

3. **Business Requirements**:
   - Any email threads about the integration
   - Screenshots from product team
   - SLA or volume requirements

## Instructions
1. Paste or save all relevant documents here **before** starting Phase 1
2. Do NOT modify these files during research or development
3. If provider updates documentation, add new version with date suffix (e.g., `api_docs_2025-01-23.pdf`)

## Next Steps
After populating this folder:
1. Fill in the `../config` file with API credentials
2. Run `/step1-epic-analysis` or `/phase1-full` to begin research
