## Authentication
### Method
Custom Auth (User ID + Secret) to obtain Bearer Token.

### Token Generation
- **Endpoint**: `POST https://api.qa.cobre.co/v1/auth`
- **Required Headers**: `Content-Type: application/json`
- **Required Credentials**: `user_id`, `secret`
- **Token Lifetime**: 1200 seconds (20 minutes)
- **Refresh Mechanism**: Re-authenticate to get a new token.

### Verification (MANDATORY)

- **Problem**: Unable to create a Payout Destination Counterparty.
- **Investigation Steps & Results**:

    2. **Transaction History**: `GET /transactions` returns 67 items, ALL are `r2p_credit` (Payin). No Payout history in QA.
    3. **Brute Force Types**:
        - `bank_account`, `beneficiary`, `payee`, etc. return `409 CP001` (Invalid Type) with minimal payload.
    4. **Payload Anomaly (Crucial Finding)**:
        - Sending `type: "bank_account"` with **Minimal Payload** (`geo: col`) -> `409 CP001`.
        - Sending `type: "bank_account"` with **Full Payload** (`name`, `identifier`, `bank_code` etc.) -> `500 Internal Server Error`.
        - **Implication**: The type `bank_account` might be valid but triggers a server crash/unhandled exception when specific fields are present/missing.
    5. **Docs Scraping**: Site is SPA, no OpenAPI spec found (`404` on standard paths).
