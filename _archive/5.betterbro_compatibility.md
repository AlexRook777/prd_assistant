**Ambiguous Statuses**:

## 4. Automation & Logic
- **Architecture Type**: HPP (Hosted Payment Page)
- **Deterministic**: Yes. The flow from creation to redirection to webhook notification is standard.
- **Webhooks**: Standard POST JSON. (Signature verification logic to be confirmed in Implementation phase).

## 5. Blocking Issues & Risks
- **RISK**: Strict document number validation in Ecuador (CI checksum). The BetterBro layer must pass valid data or handle the 400 error gracefully.
- **RISK**: Timeouts on Bank Transfer. Some bank transfers in Ecuador can be asynchronous; the `pending` status must be handled correctly.
