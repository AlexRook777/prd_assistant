## API Endpoints
### Create Transaction
- **Endpoint**: `POST https://sandbox.smartfastpay.com/v2/payin`
- **Authentication**: Bearer
- **Required Parameters**:
  - `customer.id` (string)
  - `customer.name` (string)
  - `customer.document.number` (string)
  - `customer.document.type` (string)
  - `transaction.id` (string)
  - `transaction.currency` (string)
  - `transaction.amount` (decimal)
  - `country` (string, e.g., "ECU")
  - `payment_method` (string, e.g., "bank_transfer")
  - `notification_url` (string)

### Check Status
- **Endpoint**: `GET https://sandbox.smartfastpay.com/v2/transaction/{id}`
- **Statuses**: `pending`, `paid`, `cancelled`, `refunded`
