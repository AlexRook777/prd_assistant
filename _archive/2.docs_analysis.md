## Clarified Points (User Feedback)
- **Flow**: Pure HPP via Checkout API (`/v2/transaction/checkout`).
- **Methods**: Initially Bank Transfer for Ecuador.
- **Ecuador Limits**: Min 6 USD, Max 1000 USD per transaction.
- **BetterBro Service URL**: [https://docs.betterbro.com/services/ecuador/bank_transfer/payin_hpp](https://docs.betterbro.com/services/ecuador/bank_transfer/payin_hpp)

## Authentication
### Method
OAuth 2.0 with Bearer Token (Client Credentials flow).
### Token Generation
- **Endpoint**: `POST https://sandbox.smartfastpay.com/oauth2/token`
- **Required Headers**: 
    - `Authorization: Basic <EncodedClientIdClientSecret>`
    - `Content-Type: application/json`
    - `Accept: application/json`

## API Endpoints
### Create Transaction (Checkout)
- **Endpoint**: `POST https://sandbox.smartfastpay.com/v2/transaction/checkout`
- **Authentication**: Bearer Token
- **Required Parameters**:
  - `customer.id` (string)
  - `transaction.id` (string)
  - `transaction.currency` (string, e.g., "USD")
  - `transaction.amount` (decimal, e.g., 25.00)
  - `country` (string, ISO 3166-1 alpha-3, e.g., "ECU")
  - `payment_method` (array of strings, e.g., ["bank_transfer"])
  - `notification_url` (string)
- **Optional/Pre-fill Parameters**:
  - `customer.name` (Optional on Checkout)
  - `customer.email` (Optional on Checkout)
  - `customer.document.number` (Optional on Checkout)
  - `customer.document.type` (CI, RUC, PA for ECU)
  - `redirect_url`

### Check Status
- **Endpoint**: `GET https://sandbox.smartfastpay.com/v2/transaction/{id}`
- **Statuses**: `pending`, `paid`, `cancelled`, `refunded`.

### Webhook Callback
- **Format**: POST (JSON)
- **Security Check**: Signature details available in Dashboard (typically via a shared secret if configured).
