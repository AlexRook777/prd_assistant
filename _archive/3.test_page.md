# Test Page: SmartFastPay Ecuador USD Payin HPP

This page allows you to physically verify the SmartFastPay API behavior, test token generation, and simulate transactions for Ecuador (USD) using the Bank Transfer HPP flow.

## Files
- **Test Page**: [3.test_page.html](file:///home/worker/repos/prd_assistant/integrations/Integration_SmartFastPay%20Ecuador%20USD%20Payin%20HPP/1_research/3.test_page.html)

## Prerequisites
1.  **Local Proxy Server**: Ensure the local proxy server is running:
    ```bash
    python3 app/serve.py
    ```
    This provides the `/proxy` and `/webhook` endpoints.

## Usage Instructions

### 1. Authentication
1.  Open [3.test_page.html](file:///home/worker/repos/prd_assistant/integrations/Integration_SmartFastPay%20Ecuador%20USD%20Payin%20HPP/1_research/3.test_page.html) in your browser.
2.  Toggle **Use Proxy** to **ON** (top right of API Credentials card).
3.  Enter your `CLIENT_ID` and `CLIENT_SECRET` from the `config` file.
4.  Click **Get Token**.
5.  Check the **API Logs** tab to verify the response.
    - *Note: If you receive a 401, verify credentials in Jira or with the provider.*

### 2. Creating a Transaction
1.  Fill in the **Create Transaction** form.
    - Defaults for Ecuador (USD) are pre-filled.
    - Ensure `customer.document.number` is a valid Ecuador ID (CI).
2.  Click **Create Transaction**.
3.  If successful, a **Payment Link** will appear. Click it to open the SmartFastPay HPP in a new tab.

### 3. Verifying Results
1.  **API Logs**: View all outgoing requests and incoming responses.
2.  **Webhooks**: Switch to the **Webhooks** tab. It polls every 5 seconds for new events received by `http://localhost:8000/webhook`.
3.  **Check Status**: After interacting with the HPP, use the **Check Status** button to manually poll for the transaction state.

## Troubleshooting
- **CORS Errors**: Ensure the "Use Proxy" toggle is ENABLED.
- **401 Unauthorized**: SmartFastPay sandbox often has sensitive credential/endpoint pairings. Verify the `base-url` and endpoint in `2.docs_analysis.md`.
- **Invalid ID**: Use a valid 10-digit Ecuador CI for testing.
