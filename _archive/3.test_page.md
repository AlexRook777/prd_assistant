# Test Page Usage Instructions

This page allows for physical verification of the SmartFastPay Ecuador USD Payin HPP integration.

## Files
- [3.test_page.html](file:///home/worker/repos/prd_assistant/integrations/Integration_SmartFastPay%20Ecuador%20USD%20Payin%20HPP/1_research/3.test_page.html)

## How to use
1.  **Start Proxy**: Ensure the local proxy server is running (`python3 app/serve.py`).
2.  **Open Page**: Open [3.test_page.html](file:///home/worker/repos/prd_assistant/integrations/Integration_SmartFastPay%20Ecuador%20USD%20Payin%20HPP/1_research/3.test_page.html) in your browser.
3.  **Get Token**: Click "Get Token" in the API Credentials card.
4.  **Create Transaction**: 
    - Fill in the transaction details (or use defaults).
    - Click "Create Transaction".
    - A payment link will be generated.
5.  **Complete Payment**: Click the payment link to open the SmartFastPay HPP in a new tab. Complete the payment process there.
6.  **Verify Status**: Return to the test page and click "Check Status" to see the updated transaction state.
7.  **Verify Webhooks**: Switch to the "Webhooks" tab to see real-time notifications received from the provider.
