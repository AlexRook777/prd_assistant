# Test Page: SmartFastPay Ecuador USD Payin HPP

**Page:** [3.test_page.html](3.test_page.html)

## Usage Instructions

1.  **Start Local Server**:
    Ensure the Python server is running to handle webhooks and proxying.
    ```bash
    python3 app/serve.py
    ```

2.  **Open Test Page**:
    Navigate to:
    `http://localhost:8000/integrations/Integration_SmartFastPay_Ecuador_USD_Payin_HPP/1_result/3.test_page.html`

3.  **Authentication**:
    -   Credentials (Client ID/Secret) are pre-filled (from configuration).
    -   Click **"Get Access Token"** to retrieve a Bearer token via the Proxy (or direct if valid CORS). *Note: Sandbox usually requires Proxy/Backend for `oauth2/token` due to CORS.*
    -   **Recommendation**: Enable **"Use Proxy"** switch.

4.  **Create Transaction**:
    -   **Transaction ID** is auto-generated (UUID).
    -   **Amount**: Default 10.00 USD.
    -   **Customer**: Pre-filled with valid dummy data (CI 1710034065).
    -   Click **"Create Transaction"**.
    -   If successful, a **Payment Link** will appear. Click it to simulate payment.

5.  **Webhooks**:
    -   The page automatically polls for webhooks every 5 seconds.
    -   After completing payment on the HPP, check the "Webhooks" tab for the notification.
