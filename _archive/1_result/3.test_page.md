# Test Page: SmartFastPay Ecuador USD Payin HPP

This page allows for physical verification of the SmartFastPay API behavior for the Ecuador integration.

## Files
- **Functional Test Page**: [3.test_page.html](file:///home/worker/repos/prd_assistant/integrations/Integration_SmartFastPay%20Ecuador%20USD%20Payin%20HPP/1_result/3.test_page.html)

## Usage Instructions

### 1. Prerequisites
- Ensure the local proxy/webhook server is running (`python serve.py`).
- The page is configured to use the Sandbox environment by default.

### 2. Configuration
- **Proxy**: Enabled by default. Routes requests through `http://localhost:8000/proxy` to avoid CORS issues and log traffic.
- **Webhooks**: N8n mode is enabled by default. It uses a unique Order ID and polls `https://n8n.4bill.io/webhook/...` for callbacks.

### 3. Execution Flow
1. **Get Token**: Click "Get Token" to authenticate using the provided Client ID and Secret.
2. **Create Transaction**:
   - Verify the amount and currency (USD).
   - Ensure the country is `ECU`.
   - The Document Number should be a valid Ecuador ID.
   - Click "Create Transaction".
3. **Payment**:
   - Copy the generated Payment Link or click "Open Link".
   - Complete the payment flow in the sandbox environment.
4. **Verification**:
   - Check the **API Logs** for request/response details.
   - Monitor the **Webhooks** section for status updates (auto-polls every 5s).
   - Click "Check Status" for a manual status poll.

## Integration Specifics (Ecuador)
- **Document Type**: Must be `CC` (Cedula Ciudadania).
- **Currency**: `USD`.
- **Payload Structure**: Uses the corrected payload structure identified in Step 2 (`customer.id` and `customer.id_type` instead of nested `document`).

## Workflow Suggestions
- **Automated Testing**: Run `/step4-auto-test-page` next to automatically verify this page using a browser agent.
- **Gap Verification**: Use the "API Logs" to confirm that the provider correctly handles the `amount` as either a string or number.
