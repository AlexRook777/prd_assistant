# Epic Analysis

**Integration Name**: SmartFastPay - Ecuador - USD - Bank Transfer  
**Date**: 2026-02-05

## Summary
The integration aims to add **SmartFastPay** as a payment provider for **Ecuador**, specifically for **Bank Transfer (Payin)** in **USD**. While the provider supports other regions (like Peru), they are excluded from this specific integration scope. The flow follows the **HPP (Redirect)** model, obtaining a payment URL via API.

## Clarified Points (User Feedback)
- **Scope Refinement**: This integration is limited to **Ecuador (USD)** only.
- **Excluded Regions**: Peru (PEN) is explicitly **not** included in this integration.

## BetterBro Alignment (Draft)

- **BetterBro Service URL**: https://docs.betterbro.com/services/ecuador/bank_transfer/payin_hpp

## Requirements
- **Payment Method**: Bank Transfer.
- **Country/Currency**: Ecuador (USD) only.
- **Flow Type**: HPP (Redirect).
- **Transaction Types**: Payin.
- **Customer Mandatory Fields**: Amount, name, tax_id_type, tax_id, email (used for pre-filling).
- **Transaction Limits (Ecuador)**:
    - Min: 6 USD
    - Max: 1,000 USD
    - Daily User Limit: 1,200 USD
    - Monthly User Limit: 36,000 USD
