## Authentication
### Method
OAuth 2.0 with Client Credentials (Bearer Token)

### Token Generation
- **Endpoint**: `POST https://api.smartfastpay.com/oauth2/token` (Production) / `https://sandbox.smartfastpay.com/oauth2/token` (Sandbox)
- **Required Headers**: `Content-Type: application/x-www-form-urlencoded`
- **Required Credentials**: Basic Auth (client_id:client_secret)
- **Body**: `grant_type=client_credentials`
- **Token Lifetime**: 3600 seconds (1 hour)

### Verification (MANDATORY)
Successfully verified. Obtained token using:
```bash
curl -v -u "CLIENT_ID:CLIENT_SECRET" -d "grant_type=client_credentials" https://sandbox.smartfastpay.com/oauth2/token
```
**Response**:

```json
    "data": {
        "access_token": "eyJ0eXAi...",
        "token_type": "Bearer",

}
```

## Transaction Initiation
### Create Transaction Endpoint
- **Endpoint**: `POST https://api.smartfastpay.com/v2/transaction/checkout` (Production) / `https://sandbox.smartfastpay.com/v2/transaction/checkout` (Sandbox)
- **HTTP Method**: POST
- **Request Format**: application/json
- **Authentication**: Bearer Token in Authorization header

### Data Structure
#### Mandatory Fields
| Field | Type | Format | Description | Example |
|-------|------|--------|-------------|---------|
| `transaction.amount` | number | Decimal(10,2) | Transaction amount | 100.50 |
| `transaction.currency` | string | ISO 4217 | Currency code | "USD" |
| `transaction.id` | string | UUID/String | Unique Merchant Transaction ID | "ff906669..." |
| `country` | string | ISO 3166-1 alpha-3 | Country Code | "ECU" |
| `customer.name` | string | String | Full Name | "Test User" |
| `customer.id` | string | String | Document Number (Primary ID) | "1701234567" |
| `customer.id_type` | string | String | Document Type (Must be `CC` for ECU) | "CC" |
| `notification_url` | string | URL | Webhook URL | "https://..." |

#### Optional Fields
| Field | Type | Format | Description | Defaults |
|-------|------|--------|-------------|----------|
| `customer.email` | string | Email | Customer Email (Docs say optional, verified optional) | - |
| `redirect_url` | string | URL | Redirect URL after payment | - |
| `branch` | string | String | Branch identifier | - |

#### Nested Structures
- **customer**: Object containing `id`, `name`, `email` (optional), `document` (`number`, `type`).
- **transaction**: Object containing `id`, `amount`, `currency`.

### Expected Results
- **Success Status Code**: 200 OK
- **Response Structure**:
```json
{
  "requestId": "...",
  "data": {
    "url": "https://sandbox-checkout.smartfastpay.com/v1/...",
    "transaction_id": "87aa5838-...",
    "expires_in": 1770283517
```

- **Transaction ID Location**: `data.transaction_id` (Provider ID)
