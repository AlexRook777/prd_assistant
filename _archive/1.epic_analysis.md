# Epic Analysis

**Integration Name**: SmartFastPay - Ecuador - USD - HPP  
**Date**: 2026-02-04

## Summary
The integration involves adding SmartFastPay as a provider for Bank Transfers in Ecuador (USD). The primary flow is a Hosted Payment Page (HPP) through the provider's checkout. The integration is expected to handle Payin transactions. Peru (PEN) was initially mentioned but is excluded from the current scope per user instruction.

## BetterBro Alignment (Draft)
- **Service Rule**: Bank Transfer / HPP
- **BetterBro Service URL**: [https://docs.betterbro.com/services/ecuador/bank_transfer/payin_hpp](https://docs.betterbro.com/services/ecuador/bank_transfer/payin_hpp)

## Clarified Points (User Feedback)
- **HPP Flow**: It is confirmed that the integration will be HPP (Hosted Payment Page).
- **Payout Scope**: Payout (Withdrawal) is NOT required for this stage.
- **Geographic Scope**: Only **Ecuador (USD)** is to be processed. **Peru (PEN)** is excluded from this phase.

## Requirements
- **Payment Method**: Bank Transfer
- **Countries/Currencies**:
    - **Ecuador**: USD
- **Flow Type**: HPP (Redirect to Checkout)
- **Transaction Types**: Payin
- **Volume/Limits (Ecuador)**:
    - **Min**: 6 USD
    - **Max**: 1,000 USD
    - **User Daily Max**: 1,200 USD
    - **User Monthly Max**: 36,000 USD
- **Language Support**: Spanish, English
- **Merchant Fields**: Amount, name, tax_id_type, tax_id, email.

## Technical Constraints
- Integration via SmartFastPay [Checkout](https://docs.smartfastpay.com/thesmartway/checkout-experience/overview).
- API Documentation is noted as "not quite actual" (not fully up to date).
- Request for creation does NOT require `customer_fields` if they are not already provided (checkout handles them).
- Testing and Production credentials are already available.
