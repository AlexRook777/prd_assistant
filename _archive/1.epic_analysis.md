# Epic Analysis

**Integration Name**: SmartFastPay - Ecuador - USD - Bank Transfer (HPP)
**Date**: 2026-01-30

## Summary
- **Payment Method**: Bank Transfer (and other checkout-supported methods)
- **Countries**: Ecuador, Peru
- **Currencies**: USD, PEN
- **Flow Type**: HPP (Hosted Payment Page via Checkout)
- **Transaction Types**: Payin

The integration will use the SmartFastPay Checkout flow, which provides a hosted payment page where users can complete their transactions. If customer data is not provided in the initial request, the user can enter it directly on the HPP.

## BetterBro Alignment (Draft)
- **Service Rule**: Bank Transfer / Payin HPP
- **BetterBro Service URL**: https://docs.betterbro.com/services/ecuador/bank_transfer/payin_hpp

## Requirements
- Integration via the [SmartFastPay Checkout API](https://docs.smartfastpay.com/thesmartway/checkout-experience/overview).
- Request returns a `pay_url` for user redirection.
- Limits for Ecuador (USD):
  - min 6 USD per transaction
  - max 1,000 USD per transaction
  - max daily 1,200 USD per user
  - max monthly 36,000 USD per user
- Limits for Peru (PEN):
  - min 25 PEN (~7 USD)
  - max 3700 PEN (~1,000 USD)
  - max daily 11,100 PEN (~3,000 USD)
  - max monthly 18,500 PEN (~5,000 USD)
- Target conversion rate: 70%+.
- Support Spanish and English languages.

## Technical Constraints
- Integration timeline: Initially Bank Transfer, followed by other methods.
- Testing environment: Sandbox available with credentials provided (`management@mailhub.services`).
- Customer fields: Optional in the create request; can be filled on the HPP.
