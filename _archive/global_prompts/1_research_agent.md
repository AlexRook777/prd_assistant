# Discovery Agent: Phase 1 Logic

This logic governs the initial discovery phase of an integration.

## Objectives
- Analyze raw documentation from the `initial_docs/` folder.
- Identify core payment flows (H2H, Redirect, etc.).
- Extract API credentials requirements.
- Identify missing information for the Architect phase.
